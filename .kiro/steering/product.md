# Product Overview

Guppy Web System は、投資判断に関わる日次更新データを閲覧するための Web システムです。匿名ユーザーには公開トップで集計サマリを提供し、認証済みユーザーにはシステム横断サマリ、システム別最新結果、ウォッチリストを提供します。

このリポジトリは Web システムの公開 UI、参照専用 API、設計資料、開発環境を管理します。売買ロジックや日次集計バッチの本体は別リポジトリで管理し、このリポジトリには持ち込みません。

## Core Capabilities

- 公開トップでサービス概要、匿名集計、最終更新時刻を提示する
- 認証後画面でシステム横断の状態確認と個別システムの最新結果確認を行う
- ウォッチリストや公開サマリなどの画面向けデータを、参照専用 API 経由で取得する
- 要件、基本設計、画面設計、運用設計をリポジトリ内ドキュメントとして維持する

## Target Use Cases

- 公開サイト訪問者が、サービスの概要と直近の匿名集計状況を短時間で把握する
- 運用担当者や認証済み利用者が、ログイン後画面で最新結果と対象銘柄一覧を確認する
- 開発者が、フロントエンド、バックエンド、設計資料を同じリポジトリで追跡しながら機能追加する

## Product Boundaries

- このリポジトリの主対象は「閲覧系 Web システム」であり、更新系業務処理は責務外とする
- 公開 API は匿名集計のみを返し、個別銘柄や機密性の高い生データは公開しない
- 認証後 API は画面表示に必要な参照データ提供に限定し、バッチ起動や業務更新操作は扱わない
- 業務日付や集計基準は JST の意味を保ったまま画面と API に反映する

## Value Proposition

- 公開導線と認証後導線を分けつつ、単一の Web システムとして一貫した閲覧体験を提供できる
- フロントエンド、参照専用 API、設計資料を同じリポジトリで管理し、仕様と実装の乖離を抑えやすい
- 機密ロジックを別リポジトリへ分離することで、公開リポジトリ側の責務と公開範囲を明確にできる

---
_目的、責務境界、価値に関する判断基準を記録し、個別画面や API 一覧の完全な台帳にはしない_
