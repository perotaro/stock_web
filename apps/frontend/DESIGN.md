# Guppy DESIGN.md

## 1. ビジュアルテーマと空気感

Guppy のサイト全体のデザインテーマは、「高コントラストで静かな運用ダッシュボード」です。派手な演出や借り物のブランド感ではなく、更新されていること、情報が整理されていること、業務 UI として信頼できることを短時間で伝えることを優先します。サイト全体では、暗色の構造要素と明色の情報面を切り替えながら、画面の重心と情報の優先順位を自然に誘導します。

共通フレームとして、ヘッダは暗色帯、主要コンテンツは白または淡い無彩色の面で構成します。暗色面は強いコントラストで「構造」と「導線」を担い、明色面は「情報」と「操作の理解」を担います。この役割分担を崩さず、装飾のための背景写真や強いグラデーションは使いません。

タイポグラフィは、日本語可読性を最優先にしたサンセリフを使います。見出し、本文、数値、補助情報で階層を明確に分け、数値やページタイトルだけを強く見せます。ブランド識別子は文字組みでも画像でも構いませんが、現在の基準は横長ロゴ画像です。暗色ヘッダ上で十分に識別できる明色主体の透過画像を使い、縦方向のサイズで拡大縮小します。

**主な特徴:**

- 暗色の構造面と明色の情報面を切り替えて、画面のリズムを作る
- 主要な色は中立色 + 単一アクセントで構成し、配色を増やしすぎない
- 主要見出しとデータ値を強く見せ、本文は読みやすさを優先する
- 角丸は小さく統一し、硬質で整理された印象を維持する
- 写真や装飾イラストに依存せず、面構成と文字組みで成立させる
- 特定企業や高級ブランドを連想させるモチーフを持ち込まない

## 2. カラーパレットと役割

### 主要ブランドカラー

- **Hero Background** (`#172033`): ヘッダ、暗色帯、ヒーローなど構造的に強い面
- **Hero Text** (`#F8FAFC`): 暗色面上の主要文字色
- **Accent** (`#0F766E`): 主要ボタン、アクティブ導線、操作要素の強調色
- **Accent Strong** (`#115E59`): hover、pressed など 1 段強い操作状態
- **Focus** (`#0B5FFF`): キーボードフォーカスとアクセシビリティ上の強調色

### ニュートラルスケール

- **Background** (`#EEF2F4`): サイト全体の背景、中間面
- **Subtle Surface** (`#E7ECEF`): 説明領域、補助パネル、控えめな面
- **Surface** (`#FFFFFF`): カード、主要コンテンツ、入力面
- **Ink** (`#172033`): 明色面上の主要文字色
- **Muted** (`#627086`): 補助文字、説明文、ラベル
- **Border** (`#D8E0E7`): 区切り線、境界線、カード枠

### インタラクティブ状態

- 主要ボタン: 背景 `Accent`、文字 `Hero Text`、hover は `Accent Strong`
- セカンダリボタン: 背景 `Surface`、文字 `Ink`、境界線 `Border`
- テキストリンク: 明色面では `Ink`、hover で `Accent` に寄せる。暗色面では `Hero Text` を使う
- インラインリンク: 下線は既定で付けず、hover または文脈で必要な場合のみ明確化する
- フォーカス: `2px solid #0B5FFF`、`outline-offset: 2px`

### シャドウ

- サイト全体で使う影は 1 種類に限定する
- 基準シャドウは `0 8px 18px rgba(23, 32, 51, 0.04)` とする
- 影は補助的な奥行きとしてのみ使い、面の切り替えを優先する

## 3. タイポグラフィルール

### フォントファミリー

- **共通フォント**: `Noto Sans JP`
- **フォールバック**: `Hiragino Sans, Yu Gothic UI, sans-serif`

### ヒエラルキー

| 役割                      | フォント     | サイズ    | ウェイト | 行間      | 備考                   |
| ------------------------- | ------------ | --------- | -------- | --------- | ---------------------- |
| ページタイトル            | Noto Sans JP | 32px–40px | 700      | 1.15–1.25 | 画面の主見出し         |
| セクション見出し          | Noto Sans JP | 24px      | 600–700  | 1.25      | セクションタイトル     |
| ナビゲーション / 小ボタン | Noto Sans JP | 14px      | 600      | 1.0–1.2   | ヘッダ導線、補助ボタン |
| データ値                  | Noto Sans JP | 28px–32px | 600–700  | 1.0–1.15  | メトリクス、主要数値   |
| 本文                      | Noto Sans JP | 16px      | 400      | 1.5       | 標準本文               |
| 補助文字                  | Noto Sans JP | 12px–14px | 400–500  | 1.4–1.5   | ラベル、メタ情報       |

### 原則

- ページタイトルは 32px–40px の範囲で使い、画面の格を揃える
- 本文は常に 16px / line-height 1.5 を基本にし、密度を上げすぎない
- データ値は本文より少なくとも 2 段階大きくする
- 小ラベルは 12px–14px で統一し、過剰に主張させない
- 全角日本語を前提に、字間調整や極端な uppercase 運用は行わない

## 4. コンポーネントスタイル

### ボタン

- 高さ: モバイル 36px、デスクトップ 40px
- 横 padding: 14px–16px
- 文字: 14px、ウェイト 600
- 角丸: 4px
- 主要ボタン: `Accent` 塗り
- セカンダリボタン: `Surface` 背景 + `Border` 枠
- 1 画面内で主要ボタンを増やしすぎず、最も重要な導線だけを強くする

### カードとコンテナ

- カード背景は `Surface`
- 境界線は `1px solid Border`
- 角丸は 4px
- カード内余白は 16px–20px
- 補助説明ブロックは必ずしもカード化せず、`Subtle Surface` や余白で分ける

### ナビゲーション

- ヘッダは全画面共通で暗色帯を基本とする
- ロゴ画像を使う場合は、モバイル 24px、デスクトップ 40px–44px を基準とする
- ヘッダ内の文字、アイコン、ロゴは暗色面上で沈まないコントラストを確保する
- ヘッダはヒーローや本文に重ねず、独立した帯として描画する

### 画像表現

- サイト全体で装飾写真は使わない
- 許容する画像は、ブランド識別用ロゴ、必要な図表、意味のあるプロダクト画像に限定する
- 単なる雰囲気作りのための写真、テクスチャ、イラストは使わない
- 画像がなくても成立することを前提に、レイアウトと文字組みを設計する

## 5. レイアウト原則

### スペーシングシステム

- 基本単位: 8px
- スケール: `8 / 12 / 16 / 24 / 32 / 48`
- セクション間の縦余白: 48px を基準とする
- カード間ギャップ: 16px を基準とする

### グリッドとコンテナ

- ヘッダは全幅帯とする
- メインコンテンツは中央寄せコンテナを使い、最大幅は `1152px` を目安とする
- 情報ページは 1 カラム主体、データカードや一覧だけを必要に応じて 2 カラム以上にする
- 読み物と数値面を同じ密度で並べず、役割ごとに面を分ける

### 余白の哲学

- 面の役割が変わる場所では、色の切り替えと同時に 32px–48px の縦余白を設ける
- 1 セクション内の情報密度は揃え、急に詰め込まない
- 主要な導線の周囲には最低 16px 以上の余白を取り、誤操作を防ぐ

### ボーダー半径スケール

- 既定は 4px
- 0px は特殊な表現としてのみ使う
- 8px 以上の角丸は基本的に使わない

## 6. 奥行きとエレベーション

| レベル              | 処理                            | 用途                       |
| ------------------- | ------------------------------- | -------------------------- |
| ダーク（Level 0）   | `Hero Background` 面            | ヘッダ、構造帯、ヒーロー   |
| フラット（Level 1） | `Surface` + 1px 境界線          | カード、主要パネル         |
| 中間面（Level 2）   | `Background` / `Subtle Surface` | 補助説明、区切りセクション |

**シャドウの考え方**: サイト全体のレイヤは、まず背景面の色差で表現します。シャドウはカードや浮遊パネルにだけ補助的に使い、視線誘導の主役にしません。暗色帯、白サーフェス、中間面の順で明度差を付け、レイヤの違いを判断できるようにします。

## 7. Do と Don't

### Do

- 暗色の構造帯と明色の情報面という役割分担を守る
- 色は中立色 + 単一アクセントで整理する
- 見出し、本文、数値のサイズ差を明確にする
- ロゴ、リンク、ボタンのコントラストを十分に確保する
- 説明ブロックは必要に応じてカード化せず、余白と面で分ける
- 実装時は 4px 角丸、1px 境界線、16px–20px 内余白を基準にする

### Don't

- ページ全体をカードだらけにしない
- 強いグラデーション、装飾写真、借り物の高級感を持ち込まない
- 1 画面に主要アクションを複数乱立させない
- 暗色面上で暗い文字色を使わない
- 本文を 14px 以下へ落として読みづらくしない
- 角丸やシャドウを場当たり的に増やさない

## 8. レスポンシブ挙動

### ブレークポイント

| 名称          | 幅               | 主な変化                         |
| ------------- | ---------------- | -------------------------------- |
| Mobile        | `< 768px`        | 単一カラム、ロゴ高さ 24px        |
| Desktop       | `768px - 1023px` | ロゴ高さ 40px、カード 2 列が安定 |
| Large Desktop | `>= 1024px`      | ロゴ高さ 44px、余白を拡張        |

### 収縮戦略

- ページタイトル: モバイルでは 32px、デスクトップでは 40px
- ヘッダ上下 padding: モバイル 20px、デスクトップ 20px を基準に維持
- ロゴ画像: モバイル 24px、デスクトップ 40px–44px
- カードレイアウト: 横並びは 768px 以上から、未満では 1 カラム
- 説明文はモバイルでも 16px を維持し、行数で調整する

## 9. エージェント向けプロンプトガイド

### クイックカラーリファレンス

- 暗色帯: `#172033`
- 暗色帯文字: `#F8FAFC`
- 背景: `#EEF2F4`
- 補助面: `#E7ECEF`
- サーフェス: `#FFFFFF`
- 本文色: `#172033`
- 補助文字: `#627086`
- 境界線: `#D8E0E7`
- アクセント: `#0F766E`
- hover アクセント: `#115E59`
- フォーカス: `#0B5FFF`

### コンポーネント用プロンプト例

- 「暗色の構造帯を持つレイアウトを作成。ロゴは左、主要導線は右。暗色面上では `#F8FAFC` 系を使う。」
- 「情報カードを作成。背景 `#FFFFFF`、境界線 `#D8E0E7`、角丸 4px、内側余白 16px–20px。」
- 「ページタイトルを作成。サイズ 32px–40px、ウェイト 700、本文は 16px / 1.5。」
- 「補助説明セクションを作成。カード化せず、`#E7ECEF` 系の中間面と余白で区切る。」

### 改善時の指針

1. まず面の役割を整理し、その後で個別コンポーネントを調整する
2. 抽象語ではなく、色、サイズ、余白、角丸に落として判断する
3. 主要アクションの数を増やす前に、画面の目的を再確認する
4. 写真や装飾を足す前に、文字組みだけで成立しているか確認する
5. サイト全体の一貫性を優先し、画面ごとの例外を増やしすぎない
